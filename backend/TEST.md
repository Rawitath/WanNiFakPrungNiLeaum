# 🐔 สูตรข้าวมันไก่

> "The ultimate open-source comfort food architecture." 
> สูตรข้าวมันไก่ระดับโปรดักชัน เนื้อไก่นุ่มฉ่ำ ข้าวมันเรียงเม็ด น้ำจิ้มซอสเข้มข้นจัดเต็ม

----

## 🛠️ System Dependencies (วัตถุดิบ)

### 1. Main Chicken & Broth (ส่วนประกอบไก่ต้มและน้ำซุป)
*   `chicken_whole` : ไก่สดทั้งตัว (หรือสะโพก/อกตามชอบ) **1 กิโลกรัม**
*   `coriander_roots` : รากผักชี **3-4 ราก**
*   `garlic_cloves` : กระเทียมจีนบุบ **5 กลีบ**
*   `ginger_sliced` : ขิงแก่ฝานแว่น **4-5 ชิ้น**
*   `salt` : เกลือป่น **1 ช้อนโต๊ะ**

### 2. Rice Architecture (ส่วนประกอบข้าวมัน)
*   `jasmine_rice` : ข้าวหอมมะลิเก่า **2 ถ้วยตวง**
*   `chicken_fat` : มันไก่ดิบ (เอามาเจียวน้ำมัน) **100 กรัม**
*   `garlic_minced` : กระเทียมสับละเอียด **2 ช้อนโต๊ะ**
*   `ginger_minced` : ขิงสับละเอียด **1 ช้อนโต๊ะ**

### 3. Dipping Sauce Module (ส่วนประกอบน้ำจิ้ม)
*   `fermented_soy_bean` : เต้าเจี้ยวอย่างดี **3 ช้อนโต๊ะ**
*   `black_soy_sauce` : ซีอิ๊วดำหวาน **1 ช้อนโต๊ะ**
*   `vinegar` : น้ำส้มสายชู **2 ช้อนโต๊ะ**
*   `sugar` : น้ำตาลทราย **1 ช้อนโต๊ะ**
*   `chili_&_ginger` : พริกขี้หนูสวนและขิงแก่สับ **ตามชอบ**

## ⚡ Deployment Steps (ขั้นตอนการทำ)

### Step 1: `Build-Chicken-Broth` (ต้มไก่)
1. ตั้งหม้อใส่น้ำให้ท่วมตัวไก่ ใส่รากผักชี กระเทียม ขิง และเกลือ เปิดไฟแรงจนเดือด
2. ลดไฟลงเป็นไฟอ่อน ค่อยๆ หย่อนไก่ลงไปต้ม ห้ามให้น้ำเดือดพล่าน (เพื่อรักษาความฉ่ำของเนื้อไก่)
3. ต้มทิ้งไว้ประมาณ **30-40 นาที** จนไก่สุก ช้อนไก่ขึ้นมาพักในน้ำเย็นทันทีเพื่อความเด้ง ส่วนน้ำซุปเก็บไว้หุงข้าวและซด

### Step 2: `Execute-Rice-Cooking` (หุงข้าวมัน)
1. นำมันไก่ลงไปเจียวในกระทะจนได้น้ำมัน คัดกากไก่ออก
2. ใส่กระเทียมและขิงสับลงไปผัดจนส่งกลิ่นหอม
3. ใส่ข้าวสารที่ล้างสะอาดแล้วลงไปผัดคลุกเคล้าให้น้ำมันเคลือบเม็ดข้าวทุกเม็ด
4. ย้ายข้าวไปใส่หม้อหุงข้าว เติมน้ำซุปไก่ที่ต้มไว้ (ใช้อัตราส่วนเท่าการหุงข้าวปกติ) แล้วกดสวิตช์หุงตามปกติ

### Step 3: `Compile-Sauce` (ทำน้ำจิ้ม)
1. ผสมเต้าเจี้ยว, ซีอิ๊วดำหวาน, น้ำส้มสายชู และน้ำตาลทรายเข้าด้วยกัน คนจนน้ำตาลละลาย
2. ใส่พริกขี้หนูสับและขิงสับลงไปผสม ชิมรสชาติให้ได้ 3 รส (เปรี้ยว เค็ม หวาน) ตามใจชอบ

## 🍽️ Usage (วิธีเสิร์ฟ)

```bash
\$ ช้อนข้าวมันร้อนๆ ใส่จาน
\$ สับไก่ต้มชิ้นหนาๆ วางโปะด้านบน (ห้ามตบไก่!)
\$ ราดซอสน้ำจิ้มฉ่ำๆ พร้อมเสิร์ฟคู่กับน้ำซุปร้อนโรยผักชี
```
